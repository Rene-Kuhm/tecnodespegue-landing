# Contribuir a TecnoDespegue Landing

Gracias por tu interés en contribuir. Este proyecto es la landing page oficial de TecnoDespegue.

## Cómo contribuir

### Reportar bugs

1. Abrí un [issue](https://github.com/Rene-Kuhm/tecnodespegue-landing/issues) describiendo el problema
2. Incluí screenshots si es visual
3. Indicá navegador y dispositivo

### Proponer mejoras

1. Abrí un issue con la etiqueta `enhancement`
2. Describí la mejora y por qué es útil
3. Si podés, incluí un mockup o referencia visual

### Pull Requests

1. Forkeá el repo
2. Creá una rama descriptiva: `feat/nueva-seccion` o `fix/footer-mobile`
3. Hacé tus cambios siguiendo el estilo existente
4. Testeá en mobile y desktop
5. Abrí el PR contra `main`

## Convenciones

- **Commits**: [Conventional Commits](https://www.conventionalcommits.org/) — `feat:`, `fix:`, `docs:`, `style:`
- **Estilos**: Tailwind CSS utilities, seguir los design tokens en `global.css`
- **Componentes**: Astro components (`.astro`), un archivo por componente
- **Sin JS innecesario**: Astro es static-first — evitá client-side JS salvo que sea imprescindible

## Setup local

```bash
git clone https://github.com/Rene-Kuhm/tecnodespegue-landing.git
cd tecnodespegue-landing
npm install
npm run dev
```
